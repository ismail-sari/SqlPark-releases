# SqlPark — EKolayİş

SQL Server yedekleme ve bakım için ücretsiz, portable Windows uygulaması.

Bu depo yalnızca resmî dağıtım paketlerini içerir. Uygulama kaynak kodu ve kullanıcı kayıtları burada yayınlanmaz. Kaynak kodu için bir lisans verilmez.

ZIP paketini **Releases** bölümünden indirin. Çoğu bilgisayarda **win-x64** kullanılır; 32 bit Windows için **win-x86**, ARM Windows için **win-arm64** vardır. ZIP içindeki SqlPark.exe doğrudan çalışır. Lisans ücreti veya abonelik yoktur; ücretsiz sunucu kaydı ve e-posta onayı gerekir.

Mevcut kurulumu güncellerken **data** klasörünü koruyun. İndirilen paketlerin SHA256 değerleri sürüm sayfasında yayınlanır. Uygulama içi güncelleme ayrıca EKolayİş yayıncı imzasını ve dosya özetlerini doğrular.
